# Release v1.1.0 — Structured HTTP Logging

## Added

- Added `warn(...content)` with a yellow `WARN` tag on stderr.
- Added `http.log`, `http.warn`, and `http.error` for single-line, structured HTTP events with a timestamp, severity, context, and request details.
- Added redaction for sensitive object fields, Bearer tokens, and sensitive URL query parameters in HTTP events.
- Added TypeScript declarations for the new APIs and four tests covering output streams, event structure, redaction, and file logging.

## Changed

- Updated the README and API comments to English, with a Fastify logging example.
- Updated package keywords to describe HTTP and structured logging, file output, and redaction.
- Aligned the lockfile version with `1.1.0`.

The existing `error`, `serveur`, `logs`, `client`, and `sql` APIs remain available.
